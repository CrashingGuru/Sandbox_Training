- **Doc ID:** 3.4

## Abstract

National plan for spectrum allocation across UAE — including mmWave & beam-forming allocations. Constrains beam configurations available to operators and therefore the design of beam-traffic ML.

## Access links

- <https://tdra.gov.ae/en/telecom/telecom-regulation/spectrum-management>

## How to download

The Cowork sandbox is firewalled from direct outbound HTTP to UAE gov domains, so this file could not be fetched automatically. Two options to populate this folder:

1. **Run the top-level `download_all.sh` script** (recommended — pulls everything at once):
   ```bash
   cd "$(dirname "$0")/.."   # up to PolicyData/
   bash download_all.sh
   ```

2. **Fetch just this doc** with curl:
   ```bash
   curl -L -A "Mozilla/5.0" -o "3.4_TDRA_National_Frequency_Plan.html" "https://tdra.gov.ae/en/telecom/telecom-regulation/spectrum-management"
   ```

If the primary link fails, try the alternate URLs above.
