## How to download

The Cowork sandbox is firewalled from direct outbound HTTP to UAE gov domains, so this file could not be fetched automatically. Two options to populate this folder:

1. **Run the top-level `download_all.sh` script** (recommended — pulls everything at once):
   ```bash
   cd "$(dirname "$0")/.."   # up to PolicyData/
   bash download_all.sh
   ```

2. **Fetch just this doc** with curl:
   ```bash
   curl -L -A "Mozilla/5.0" -o "2.4_UAE_Federal_Open_Data_Policy.html" "https://tdra.gov.ae/en/open-data/open-data-policy"
   ```

If the primary link fails, try the alternate URLs above.
