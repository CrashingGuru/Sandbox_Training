## 3. Provenance notes — how the files were retrieved

### 3.1 What the four provenance tags mean

- ✅ **Official PDF** — the authoritative document, fetched directly from the issuing entity's servers. 7 files: 1.2 AI Charter, 2.1 PDPL, 3.2 TDRA Consumer Protection, 3.4 TDRA Spectrum WP, 4.1 Cybersecurity Strategy, 5.1 NCEMA 7000:2021 (CORE mirror), 5.1b NCEMA 7000:2012 (Wayback API + `if_`).
- 📄 **Official portal HTML** — the live u.ae / ministry page rendered as HTML. Full policy PDF may not be publicly downloadable, but the portal page contains the abstract, key clauses and links.
- 🕰️ **Wayback Machine snapshot** — retrieved via `web.archive.org` because the source site is **geoblocked from non-UAE IPs**. The user's ISP could not reach these domains at all. Live URLs still work from within the UAE.
