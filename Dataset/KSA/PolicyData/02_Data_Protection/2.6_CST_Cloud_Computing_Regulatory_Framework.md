# Cloud Computing Regulatory Framework (CST)

- **Doc ID:** 2.6
- **Issuing body:** Communications, Space & Technology Commission (CST, formerly CITC)
- **Referenced in notebook row(s):** 9, 10
- **Target filename (once downloaded):** `2.6_CST_Cloud_Computing_Regulatory_Framework.pdf`

## Abstract

CST framework for cloud service providers operating in Saudi Arabia — service-level classes, data-locality rules, security controls, liability. Interacts with PDPL cross-border transfer clauses.
